About User Management System

A centralized platform to manage users, products, and reports efficiently.

🚀 Purpose

This system helps organizations manage users, assign roles, track products, and generate reports from a single dashboard.

✨ Features

  • User & role management
  • Product inventory control
  • Monthly & yearly reports
  • Secure authentication & authorization
  • Modern dashboard UI

🛠 Technology Stack

  • Angular (Frontend)
  • REST API (Backend)
  • JWT Authentication
  • Role-based access control
